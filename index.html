Resmi API Durumu ve "keyless_legacy_url" Raporu

Hata Tespiti: Önceki denemelerde alınan HTTP 403: keyless_legacy_url hatası Instagram'dan değil, anahtarsız istekleri durduran üçüncü taraf corsproxy.io servisinden kaynaklanmaktadır.

Meta Resmi Dokümantasyon Gerçeği: Meta Graph API'de rastgele kullanıcı adı uygunluğu sorgulayan resmi bir endpoint yoktur.
